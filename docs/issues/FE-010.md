# FE-010 跑通整体前端流程并交付可试用桌面窗口

父任务：[FE-000](FE-000.md)。前置：[FE-008](FE-008.md)、[FE-009](FE-009.md)，其传递依赖覆盖全部前端任务。依据：[前端执行规格](../specs/frontend-first.md)与全部子 Issue。

## 目标与范围

将各页组成一个一致、可操作、可恢复的前端；修复跨页面状态、日期、焦点和视觉问题，留下用户可以直接试用的窗口和启动说明。

验收应覆盖交互结果，不能用“组件都存在”或“TypeScript 通过”代替。当前环境缺少 Mac 不阻塞 Windows 前端交付，必须如实列出 macOS 未实测。

## 必须跑通的完整流程

1. 从空白场景新增手动订阅，修改金额和日期，查看概览、抽屉和月历同步变化。
2. 删除后撤销，重开应用确认数据与顺序保留。
3. 切换多账号、共享费用与独立额度场景，确认账单不重复、池不混用、币种不相加。
4. 切换未知、零、过时、部分成功、已过重置点，检查文案、时间与行动项。
5. 模拟认证失效、限流和离线恢复，检查保留旧值、合并任务及迟到响应隔离。
6. 预览日历差异，分别演示三个后端的阶段与失败；处理外部改期和删除。
7. 导出、预览导入并恢复，模拟日历保持暂停待核对。
8. 使用键盘走新增、详情与冲突处理；关闭回到原焦点；窄窗口和深浅色不遮挡关键操作。

## 轻量验证与交付

- 跑必要的类型检查、已有高风险纯规则测试以及一次真实桌面主流程；发现问题只补针对性检查。
- 对照 Magpie 参考确认图标、导航、卡片、右对齐数字及信息密度；不把相似配色当作完整视觉完成。
- 如已有自动化工具可复用，做少量主流程检查；不为本任务强建大规模 E2E 或 CI。
- README 给出准确启动命令和演示工具入口；交付时保留实际可打开的程序。
- 本 Issue 记录实现、验证、未实测环境和用户待验收项；父任务不能自动标为用户已验收。
- 清理仅限本次明确的临时产物；不删除用户资料、代码、尚未交付的恢复材料或参考设计。

第一轮功能开发与整体验证完成，日期：2026-10-20。负责人：主 Agent 整合；Kimi K3 桌面壳；Gemini 4 Argon Contributor 主要前端页面。分支/PR：无，本地交付。**用户反馈：视觉不接受，需重做。** 以下测试和截图是第一轮历史结果；新批次见 [FE-011](FE-011.md)，新验收由 [FE-018](FE-018.md)负责。

### 启动与检查

- 双击根目录 `启动 SubCal.cmd`，或 `npm run dev`。默认窗口已提供，可由系统托盘重新打开。
- `npm run typecheck`：通过。
- `npm run test:rules`：17/17 通过，覆盖日期锚点、金额去重、字段可用性、持久化、任务隔离、归档、同步和备份。
- `npm run test:desktop`：11/11 组通过；Playwright 操作真实 Electron 窗口，不是浏览器替代。测试使用独立临时资料目录与 `127.0.0.1:5174`，结束后清理，不覆盖试用资料。

### 实际跑通的结果

1. 四导航与十二场景逐一切换。
2. 键盘新建仅名称订阅，连续 Escape 保留未保存选择；补齐金额、10/25 续费后改为 10/28，概览/详情/月历一致。
3. 删除并在 8 秒内撤销；重启恢复记录、场景、排序与主题。多账号展开，费用按付款组去重，额度池独立。
4. 零值与尚未获取、过时与已过重置点有不同文案；模拟部分成功保留失败字段原时间。
5. 认证失效恢复向导、限流推进 5 分钟后重试、离线恢复合并补查均通过。
6. Google / EventKit / CalDAV 三后端先预览再模拟写入、读回；写入后失败可重新预览重试；键盘裁决外部改期。删除抑制及其他裁决由服务检查验证。
7. 真实 JSON 文件导出、预览、原文件变更拒绝、重新预览恢复；恢复后模拟目标暂停待核对。
8. 150% Windows 系统缩放（scaleFactor 1.5，主屏工作区 1707×1019 逻辑像素）；目标约 1280×820，缩至 960×640，深浅色、右侧 460px 抽屉和居中 560px 表单可滚动；键盘关闭恢复焦点，无页面横向溢出。
9. 编辑备注保留原字段来源、观察时间与精确重置时刻；模拟同步完成后不再把自己刚执行的清单误报为待处理冲突。
10. 真实托盘图标恢复隐藏窗口、退出菜单实际回调结束进程；安全桥拒绝 `javascript:` 链接，Renderer 无 Node 能力。
