# FE-001 打开真实桌面窗口并切换导航与主题

父任务：[FE-000](FE-000.md)。前置：无。依据：[前端规格第 1、2、6、8 节](../specs/frontend-first.md)、PRD 第 04、13 章。

## 目标与范围

建立 Electron、React、TypeScript 的最小可运行工程，让用户打开真实窗口，看到 Magpie 方向的顶部四导航和清楚的预览状态。

实现窗口与导航、主题变量、基础按钮/对话框/焦点样式、预览标记、品牌图标组件和合法来源记录。页面尚未实现的内容清楚标为待完成，不用伪造统计充数。

默认尺寸目标 1280×820；实际屏幕不够时服从可用工作区。顶部原生按钮、拖动区和可点击控件互不遮挡。提供明确的开发启动脚本与简短 README。

此任务不做真实后台、登录、数据库、安装程序或 CI。只允许为启动开发窗口所需的最小编译产物。

## 设计要求

参考 [Magpie 图片](../references/magpie-usage-reference.png)；顶部四项固定为概览、订阅、日历、连接。主题 token 集中管理，字号和颜色服从前端规格中已经校正的对比度。

Renderer 启用隔离与沙盒、关闭 Node 集成；Preload 只暴露本阶段需要的能力。真实凭据输入不能出现在初始引导里。

## 验收

- 执行 README 的一条启动命令，确实出现可操作 Electron 窗口。
- 四个导航可用鼠标与键盘切换，有当前项及可见焦点。
- 切换深浅色不丢当前页，文字和窗口控件可读。
- 在窄窗口及当前设备可用的 150% 缩放条件下检查标题栏和主要按钮；无法实测的环境记录限制。
- 使用安全的品牌资源或文字后备；没有调用供应商与日历接口。

## 当前进展

实施：Electron 44.7.0 + React + TypeScript 最小工程；原生窗口标题栏、隔离沙盒、受限文件与安全链接桥、四导航和主题框架。启动命令：`npm run dev`。

已验证：Playwright 启动真实 Electron 窗口；主屏实际 scaleFactor=1.5，工作区 1707×1019 逻辑像素，窗口约 1280×820；contextIsolation=true、sandbox=true、nodeIntegration=false。标题栏使用系统原生区域。四导航、深浅色、960×640 窄窗口均已联验，证据见 [FE-010](FE-010.md)。

品牌使用有记录的文字后备，说明见 `docs/assets.md`。分支/PR：无。用户验收：未进行；macOS 未实测。
