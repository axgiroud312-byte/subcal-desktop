# FE-008 预演 Google 和 Apple 日历同步及冲突处理

父任务：[FE-000](FE-000.md)。前置：[FE-006](FE-006.md)、[FE-007](FE-007.md)。依据：[前端规格第 5 节](../specs/frontend-first.md)、PRD 第 11 章。

## 目标与范围

完成外部日历连接设置和同步预演界面，用户能够先看将发生什么，再观察模拟过程，并处理冲突。所有变化仅发生在演示服务的目标和事件中。

三个后端分别是 Google API、macOS EventKit、iCloud CalDAV。显示示例目标、可写状态、路由说明和权限文案；在 Windows 上可切换 macOS 演示案例，但要明确这是案例而非本机调用。

预演清单从本地真实演示记录与模拟远端快照计算新增、更新、删除；相同事件改期保留逻辑 ID。只有队列提交不等于成功，阶段可暂停、失败和恢复。

Google/CalDAV 显示“模拟已排队、模拟已写入、模拟远端读回”；EventKit 终点是“模拟本机读回”，云端由系统处理且未验证。

外部改期提供本地为准、采纳为手动计划、解除管理三种动作；外部删除保留抑制标记；目标删除或只读进入需处理状态。

## 验收

- 未预览变更不能直接发起模拟同步；操作后的文案不会让用户误以为真实远端已写入。
- 三种后端的确认边界准确，同步中/失败/部分结果都有可恢复操作。
- 再次同步同一版本不生成重复模拟事件，改期更新原事件。
- 处理冲突后列表、日历、详情同步；外部删除事件不会因普通模拟刷新自动复活。
- 恢复备份或目标失效后保持暂停，不换到默认日历。
- 不弹出真实 OAuth，不收集 Apple 专用密码，不访问实际 EventKit/CalDAV/API。

## 当前进展

实施：`SyncPreview.tsx` 已提供三个模拟后端、真实计算的差异预览、分阶段写入/读回、半程失败与恢复、目标暂停/失效、三种冲突裁决和外部删除抑制。EventKit 只显示模拟本机读回；调试演练入口默认收起。取消/中断不会提示成功。

已验证：真实窗口分别预览并执行 Google、EventKit、CalDAV；Google 模拟写入后读回失败→重新预览→恢复成功；键盘采纳外部手动日期，关闭恢复焦点。重复同步不重复、改期沿用 ID、三种冲突裁决、外部删除不复活、目标暂停中断提交通过服务检查。EventKit 仅本机模拟读回；macOS 原生能力未实测。负责人：Gemini 4 Argon Contributor 实现，主 Agent 整合。分支/PR：无。用户验收：未进行。
