# FE-014 让概览一眼看懂重点，让订阅卡片轻量可扫读

父任务：[FE-011](FE-011.md)。前置：[FE-013](FE-013.md)，传递依赖 FE-012。依据：[视觉基础第 3、4.2 节](../design/visual-foundation.md)。

## 目标与范围

改造 `OverviewPage.tsx`、`SubscriptionCard.tsx` 及相关 BrandIcon、QuotaMeter、StatusBadge。交付近期事项、汇总/筛选和三类卡片的清楚层级，修复第一版粗字、嵌套框和重复文案造成的视觉拥挤。

## 实施要点

- 近期事项最多三个紧凑行，详细说明按需展开；原业务优先级有效。正常状态不铺告警卡片。
- 产品名、额度、主要余额、日期按 Token 角色排版；额度条直接放在卡片内容流中，不额外套一层带底色的框。
- 窗口额度、钱包、手动会员分别突出可用量、余额、日期/价格；手动会员没有指标时不展示无意义的额度占位区。
- 同产品多账号完整展开一个，其余保留账号和重要数据摘要，展开后不跳动当前点击目标。付款关系与额度池关系仍独立。
- 正常状态用低强调样式；过时/未知/零/重置待确认就地可见；示例标记以卡片作用域呈现，模拟刷新按钮明确标注。
- 使用真实本地品牌图标；维护 `docs/assets.md` 中的实际来源与许可。无对应资源时保持统一文字后备，不把 Lucide 普通图形冒充品牌标识。
- 筛选、密度、已用/剩余、排序、拖拽及键盘排序使用现有业务接口；刷新不扰乱顺序、位置与焦点。
- 使用 dnd-kit 接入实际卡片排序，覆盖指针、键盘和取消操作；排序结果通过现有持久化接口保存。
- 使用 Motion 处理多账号展开/收起的布局过渡；同一元素避免与 dnd-kit 同时控制 transform，开启减少动效后即时完成，焦点和当前位置稳定。

## 验收方法

- `normal_mixed`：能立即区分三类卡片，辨识主要数值和下次日期；人民币与美元分列。
- `multi_account_shared`：展开与重排可用，共用付款汇总不重复，独立额度池不混合。
- `zero_vs_unfetched`、`unknown_and_na`、`stale_and_past_reset`：数值含义直接可读，不能以“变干净”为由隐藏关键状态。
- 同场景对比旧截图，确认数字不再普遍 700 字重、卡片内部不套多层框、解释文案不挡在主要信息前。
- 两主题、默认/紧凑密度及窄窗口检查；品牌素材离线可用。附代表截图及受影响交互结果。
- 在真实卡片上验证 dnd-kit 指针/键盘排序、Escape 取消和重启恢复；验证 Motion 账号展开及 reduced-motion。记录实际组件使用位置，不能只安装依赖即标记采用。
