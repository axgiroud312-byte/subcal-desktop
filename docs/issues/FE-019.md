# FE-019 生产界面最后优化

状态：implemented，Windows 桌面已检查；用户验收：pending。前置：正式联调依赖 BE-001、BE-009；文案整理可先做。
目标：现有四页成为可日常使用的界面，没有模拟入口、自我介绍、无关小字与无关描述。
范围：沿用现有视觉、组件、布局；清除桌面默认路径的本地预览标记、模拟刷新、场景工具、演示数据、装饰性示例图表、技术栈或产品自述。精简标题副文案、空状态、详情、表单、设置与反馈。日历外部连接仅显示待接入，不提供虚假同步。
保留：实际操作所需字段标签、未知/过时/错误/待验证状态、来源和时间、权限与凭据说明（集中在连接步骤）。不得只删模拟二字而留下模拟行为。
依据：用户最新要求；docs/design/visual-foundation.md；PRD 08、09、18 C07/C08。
验收：真实 Electron 四页、设置、表单、详情中无生产可达的模拟功能或自述；空资料库可添加订阅；主题和窄窗口可用；必要状态清楚；无自动灌入假数据。验证完成不等于用户 accepted。

实施记录：App 已切换客户端选择层，预览工具仅显式开发模式按需载入；日历页去掉外部模拟写入；连接页改为真实 Key/官方客户端步骤。公共状态与来源文案已清理。前端构建、类型及既有 17 项规则通过，1280/960 宽度四页、深浅色、设置/详情/连接弹层及生产可达文案经真实桌面检查通过。截图见 backend-v1。
