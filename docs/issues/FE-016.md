# FE-016 让月历、日程与同步差异清楚易读

父任务：[FE-011](FE-011.md)。前置：[FE-012](FE-012.md)。依据：[视觉基础第 4.3 节](../design/visual-foundation.md)、[前端规格第 5 节](../specs/frontend-first.md)。

## 目标与范围

改造 `CalendarPage.tsx`、`SyncPreview.tsx` 及所属样式。月历、选中日日程、目标设置、差异预览和冲突裁决采用统一 Token 与控件，继续消费同一日程投影。

## 实施要点

- 月历标题、日期格、今天、选中日期、事件种类具有清楚层级；事件带续费/到期等文字，不只依赖颜色。
- 宽窗口月历与日程协作，窄窗口可切换月历/列表，保留选中日期；溢出事件通过“更多 N 项”查看。
- 同步设置按需打开，差异用结构化列表表达新增、改期、移除；状态阶段与失败说明使用统一组件。
- 日期选择器如确有需要，按需使用 shadcn Calendar / React DayPicker；业务月历保留事件与日期规则，不替换成仅能选日期的控件。
- 与连接页共同使用的 `calendar-connections.css` 先划清选择器归属，逐步移动到各自样式或共享组件，避免相互覆盖。

## 验收方法

- 日期边界场景检查月末、闰年、时区边界；视觉迁移不改变原日期与事件 ID。
- 窄窗口查看多事件日期、进入详情再返回，选择与滚动位置合理；两主题事件和选择态可辨识。
- `calendar_conflicts`：三后端预演、外部改期三选一、删除抑制和失败恢复仍可操作。
- Google/CalDAV 的模拟读回与 EventKit 的模拟本机确认在界面清楚区分；不能因新 Toast 统一文案而丢失边界。
- 留下月历及同步差异代表截图和受影响操作结果。

## 实际组件与样式交付

- **独占样式切分（`@layer components`，仅引用 `tokens.css` 变量）**：
  - `src/renderer/pages/calendar.css`：承载 `.cal-page`、65/35 宽窄响应式 `.cal-layout`、`.cal-grid`、`.cal-cell`、`.cal-event-pill`、`.cal-more-btn`、`.cal-agenda-card` 等月历与日程样式。
  - `src/renderer/components/sync-preview.css`：承载 `.sync-preview-root`、`.sync-backend-grid`、`.sync-backend-card`、`.sync-stage-bar`、`.sync-conflict-card`、`.sync-table-wrap` 等同步预演样式。
  - `CalendarPage.tsx` 与 `SyncPreview.tsx` 已移除对 `calendar-connections.css` 的导入，互不干扰 `ConnectionsPage`。
- **实际组件使用点**：
  - `CalendarPage.tsx`：`Button`（月份切换、回到演示今天、打开同步预演、详情与冲突操作）、`Badge`（演示今天、事件种类、预计/待确认/仅本地性质、外部目标读回与冲突状态）、`FormSelect`（`#cal-kind-filter` 按事件类型筛选、`#cal-product-filter` 按订阅产品筛选，基于 Base UI Select + Portal）、`Switch` + `Label`（显示额度重置开关，`role="switch"`）、`Tabs` / `TabsList` / `TabsTrigger`（窄窗口月历/日程切换、日程栏选中日/当月全部切换）、`BrandIcon`、`Modal`、Lucide 图标（`ChevronLeft`、`ChevronRight`、`CalendarSync`、`AlertTriangle`、`Plus`）。保留业务 `MonthGrid`（`[data-date]`、`.cal-cell`、`.cal-event-pill`、键盘方向键导航、最多 2 条事件 + “更多 N 项”），未替换为仅选日期的 DatePicker。
  - `SyncPreview.tsx`：`Button`（计算同步预演清单、执行模拟同步、冲突三选一裁决、目标状态恢复与演练、折叠触发、外部改期/删除演练、禁用态 `.ics` 导出）、`Badge`（模拟标记、目标状态、终点确认边界、变更统计与动作标签）、`Collapsible` / `CollapsibleTrigger` / `CollapsibleContent`（按需展开目标设置/路线权限说明/异常演练，以及外部改期与删除演练）、`Table` / `TableHeader` / `TableBody` / `TableRow` / `TableHead` / `TableCell`（结构化变更预览清单与远端受管事件表）、`Switch` + `Label`（模拟写入后读回失败开关，`role="switch"`）、`FormSelect`（`#sync-remote-event-select` 选择模拟远端事件）、`Modal`、Lucide 图标（`RefreshCw`、`Play`、`ChevronDown`、`SlidersHorizontal`、`AlertTriangle`）。
