# FE-006 在月历与日程列表查看订阅的真实本地安排

父任务：[FE-000](FE-000.md)。前置：[FE-005](FE-005.md)。依据：[前端规格第 5 节](../specs/frontend-first.md)、PRD 第 03、08、11 章。

## 目标与范围

将演示空间中实际保存的订阅安排投影到本地日历，不另写一套只供截图的事件数组。用户修改记录后月历、日程列表和详情一致。

宽屏使用月历加选中日列表；小窗口可切换两种视图。支持换月、回到演示今天、选日、事件类型和产品筛选；日期格最多两条，更多事件可展开。

开始、续费、到期、试用结束和重置分别用文字标识。预计和已确认分开；额度重置默认关闭且不计入扣费提醒。

继续使用 FE-002 的纯日期规则与稳定事件 ID。只有日期的安排不强转 UTC 午夜；未知日期不制造事件。生成未来计划时遵守月末和闰年锚点。

## 验收

- 新增一条订阅后在正确日期出现；改期后同一逻辑事件移动，旧日期无残留。
- 从日历打开已有详情抽屉，关闭后回到原月和选中日期。
- 一天多条事件、没有日程、长产品名及筛选无结果均可读。
- 月末、闰年与跨时区场景结果符合共有日期规则，不能因切换视图改变日期。
- 到了计划日而没有确认时显示“待确认”，不能自动写成已扣费。
- 关闭额度重置筛选后仍保留订阅续费安排，二者不互相替换。
