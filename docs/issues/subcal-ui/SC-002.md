# SC-002 在侧栏工作台到达七页面并保留导航状态

跟踪：[GitHub #45](https://github.com/axgiroud312-byte/subcal-desktop/issues/45)；父目标 [#43](https://github.com/axgiroud312-byte/subcal-desktop/issues/43)；前置 [#44](https://github.com/axgiroud312-byte/subcal-desktop/issues/44)。

## 目标与范围

父目标 SC-000。把原型 shell/index/controller 的结构迁成 React：首页、仪表盘、订阅、消费、日历、账号、设置七入口，默认仪表盘，首页可从品牌和辅助导航到达。用户要求保留的 Magpie 订阅展示直接嵌入新外壳；新侧栏下按现有卡片最小宽度自然换列。

## 局部设计

复用 App.tsx、contracts.ts、client.snapshot/subscribe 和 NotificationContext。拆 AppShell/Sidebar/Topbar/HomePage 及轻量页面状态容器；路由枚举、导航来源/返回位置统一维护，支持现有桌面返回操作。React reducer/context 保存筛选、搜索、视图、日历月份、滚动和非秘密草稿；不用主题 key 触发重挂载。

搜索组合现有 Dialog/Input/按钮结果，支持 Ctrl/Cmd+K、键盘移动/确认/Escape；页面和订阅命中共用真实 snapshot。窄窗口导航用 Sheet。保留原型宽度/断点，统一详情和新增入口。顶栏统计币种控件为后续真实偏好留接点，未接通不能伪装保存成功。

首页保持双列产品呈现，以真实记录/空态作为示意卡数据；示例仅显式开发预览可用。复用单一 Notify、模态内部反馈、8 秒撤销；不引入重复 Toast。页面后续在 SC-003—SC-008 完成业务接线，本项只验外壳及首页。

依据 `docs/design/subcal-green.md`；复用 shadcn Button/Sheet/Dialog/Input/Tooltip、Lucide、本地字体图标，registry 仍为 base-mira。旧订阅展示上下文传入详情/弹层，不随新外壳被强制套用原型字体/厚底卡片。

## 可观察验收

Electron 打开即仪表盘；七入口均可达，首页能返回工作台。搜索选择记录打开同一个详情入口，返回原页位置。切页再回来保留筛选/月份/滚动；主题切换保留输入。窄窗口菜单可键盘关闭/回焦；空库没有示例用户账单。

typecheck 和针对外壳的实际桌面操作；不把占位页算作业务页完成。

## 依赖与进展

前置 SC-001；拥有 AppShell/共享导航状态结构，其余页通过 PageProps/统一回调接入。状态 implemented：七入口、默认仪表盘、首页、Ctrl/Cmd+K 搜索、页面状态与独立滚动已接入；桌面检查通过，用户验收 pending。
