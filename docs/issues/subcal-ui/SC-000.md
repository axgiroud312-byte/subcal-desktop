## 已确定的组件和实现方式

复用 shadcn/ui `base-mira` 源码 + Base UI 1.9.0、Tailwind 4.3.3、Recharts 3.8.0、Lucide 1.60.0、Motion 14.4.0、Sonner 2.0.8 和原有 dnd-kit 排序。React 19.3.1、Electron 44.7.0；版本以实施时 lockfile 为准。本轮选型不需要新增运行时 npm 依赖。

在 `src/renderer/styles/tokens.css` 集中维护原型 `--sc-*` 和现有订阅展示角色值，避免 accent 同名不同义；同一控件通过显式 variants/context 选择呈现，旧订阅及其 Portal 不受全局字号/颜色/厚底改动污染。保留 Base UI 焦点/键盘/Portal。Nunito 用于新页面，品牌资源本地化保留许可。新外壳依 232px 侧栏、80px 顶栏和原型断点；订阅卡片/列表/详情沿当前工程，不能改为原型简化价格卡。

React 页面 → selector/ViewModel → AppClient/IPC → 现有主进程/SQLite。生产 snapshot/subscribe 是业务数据来源；临时页面状态由 React 管理。原型全页 innerHTML、事件总线、演示 localStorage 不作为生产实现。

## 共同业务约束

- 保留 Field 来源/观察时间/未知、on/off/unknown 自动续费、真实 lifecycle、多额度窗口、余额/Key 预算、账号和共享关系。自动记录只改用户本地资料，不因记账改供应商日期或额度。
- `Subscription.price` 当前没有付款日期，不是账本；新增独立付款记录、幂等、revision、实际支付日、计划关联和名称/分类快照。删除订阅保留历史付款。不能把旧 price 或供应商 usage 自动生成付款。
- 月均成本、计划预计扣费、实际已记录支出分别统计；分币种，按现有 6 位小数定点合同计算。计划按账单主体去重，实付按付款 ID；共享额度不等于共用付款。原型混合 forecast 文案按领域合同校正。
- 新增月度消费预算、统计币种、本地分类/工作区名；提醒提前天数独立于 reminder 通道。已有密度、额度显示、时区、托盘、勿扰和备份保留。
- 手动记账＋顺延同事务、按原锚点、同一期只推进一次；自动日期仍由来源确认。季度按三个日历月处理。现有 renewal:0 投影 ID 不能直接作为永久付款关联。
- 新合同贯穿类型、Zod、IPC 白名单、Client、迁移与备份；正式初始空，不灌演示库。外部日历按真实未接通状态显示。
