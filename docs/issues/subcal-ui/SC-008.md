# SC-008 保存完整偏好并可靠切换浅深和系统主题

跟踪：[GitHub #51](https://github.com/axgiroud312-byte/subcal-desktop/issues/51)；父目标 [#43](https://github.com/axgiroud312-byte/subcal-desktop/issues/43)；前置 [#45](https://github.com/axgiroud312-byte/subcal-desktop/issues/45)、[#48](https://github.com/axgiroud312-byte/subcal-desktop/issues/48)、[#50](https://github.com/axgiroud312-byte/subcal-desktop/issues/50)。

## 目标与范围

父目标 SC-000。设置由旧 Modal 迁成原型分区页面，保留密度、额度显示、时区、托盘、勿扰、备份等生产能力，整合预算、工作区名、统计币种和提前天数。

## 局部设计

复用 Settings、Preferences/setPreferences、syncDocumentTheme、exportData/importPreview/importCommit；布局为设置分区导航＋内容，使用现有 Card/Field/Input/Select/Switch/Tabs/AlertDialog 和绿色 Token。

theme preference 和 resolved theme 分离。首屏避免固定 light 闪烁；从生产偏好读取，必要启动提示不成为第二数据源。html 同步 data-theme/.dark/color-scheme，Portal 继承且保留订阅展示 variant；顶栏快捷按钮选相反显式主题，设置 light/dark/system 即时生效，system 监听变化，失败可重试且不假称保存。新页面与旧订阅各使用既定角色值，共用一个主题偏好，不增加新旧界面切换。

普通设置草稿与主题即时设置分开，后台 snapshot 刷新/主题切换不清空草稿。统计币种只切展示，预算与 Key 预算/钱包阈值独立。勿扰清空使用可持久的明确状态，修复 undefined 被默认值回填的风险；准确说明全局提醒通道和单项覆盖。

备份页面展示 SC-005 实际包含的数据和影响数量；旧“含日历同步状态”等不符生产文案修正。保留导入预览、取消、revision 校验和失败恢复。正式空间无清除演示按钮；原型浏览器本地说明改真实应用资料位置。

## 可观察验收

light/dark/system 保存重启恢复；system 下模拟系统变化，显式主题不跟随；顶栏和设置显示同步。正在输入的订阅/付款/设置草稿、当前筛选和日历月份不丢；弹层、图表和 Toast 配色一致。

保存预算/分类相关偏好后跨页及重启一致；勿扰清空后重启不悄悄恢复，密度/额度/时区/托盘仍有效。真实 Electron 走一次新备份导出/预览/取消/导入，确认账本和偏好保留、凭据不导出。

typecheck 与受影响偏好/备份测试，桌面故障注入确认可恢复；静态主题预览不替代真实 system 检查。

## 依赖与进展

完整前置 SC-002、SC-005、SC-007；主题基础由 SC-001/SC-002 先建立。本项最终整合设置草稿与全部配置。状态 implemented：分区设置页、主题即时保存与首屏预取、预算/分类/统计币种/工作区名/提前天数、v3 备份预览与恢复已接通；用户验收 pending。
