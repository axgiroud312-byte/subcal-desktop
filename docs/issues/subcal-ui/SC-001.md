# SC-001 接入原型双主题控件并保持旧订阅样式

跟踪：[GitHub #44](https://github.com/axgiroud312-byte/subcal-desktop/issues/44)；父目标 [#43](https://github.com/axgiroud312-byte/subcal-desktop/issues/43)。无前置任务。

## 目标与范围

在既有组件体系中为新外壳/消费等页面落地绿色、Nunito、厚底按钮、实线描边和深蓝灰主题；按用户要求保留旧 Magpie 订阅展示。父目标 SC-000；共同依据 `docs/design/subcal-green.md` 与原型 DESIGN-TOKENS/theme/styles，订阅展示以当前工程为基线。

## 局部设计

复用 `components.json` 的官方 shadcn `base-mira` 和 `src/renderer/components/ui/`；Button/Card/Input/Field/Select/Sheet/Dialog/AlertDialog/Tabs/Table/Chart/Sonner 等采用明确的展示 variants/context。Base UI 负责交互；Tailwind 4 + `styles/tokens.css` 为唯一 Token 值来源，base.css 做映射。现有订阅组件继续旧角色值，不复制第二套组件库。

原型 Token 加 `--sc-`；新页面 primary 映射绿色实底，accent 映射浅选中底；旧订阅保持现有颜色/字体/字号/字重/尺寸。text-base/bold、危险按钮、图表及焦点按角色映射，避免全局覆盖。移植正在使用的 Nunito/品牌图和许可，更新 docs/assets.md；中文明确回退，品牌不全局反色。新页面 Lucide 常用 20px/stroke 2、Motion 150/230ms，旧订阅按现有反馈。所有浮层跟随同一 html 主题；订阅 Portal 携带同样的展示标识，不能只给父容器设样式。

## 可观察验收

在实际 Electron 的新页面控件及旧订阅卡片/详情各查看两种主题；Escape 逐层关闭且回焦，菜单不被遮挡。新主按钮约 48px/16px/2px/4px 厚底，新统计面板约 20px 圆角；旧订阅继续当前约 12px 内边距/8px 卡距/10px 圆角和紧凑额度展示，实际字号/颜色对照基线。Nunito 断网可用。核对正文/焦点对比度，记录必要 Token 修正，不压缩整页。

运行 typecheck；按需复用现有组件桌面检查。静态样式不写镜像测试，不新增组件站。
