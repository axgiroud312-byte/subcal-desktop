# SC-003 保留 Magpie 订阅展示并接入新工作台和付款

跟踪：[GitHub #46](https://github.com/axgiroud312-byte/subcal-desktop/issues/46)；父目标 [#43](https://github.com/axgiroud312-byte/subcal-desktop/issues/43)；完整前置 [#45](https://github.com/axgiroud312-byte/subcal-desktop/issues/45)、[#48](https://github.com/axgiroud312-byte/subcal-desktop/issues/48)。

## 目标与范围

父目标 SC-000。按用户最新要求保留现有 Magpie 订阅卡片/列表/详情的样子，接入新工作台导航及分类/付款入口，保留真实 CRUD、冲突恢复、多账号和完整权益。共同依据 `docs/specs/subcal-production-ui.md`、`docs/design/subcal-green.md`、当前订阅源码和账号/权益规格。

## 局部设计

直接复用 SubscriptionsPage、SubscriptionCard、DetailDrawer、EntitlementDetails、QuotaMeter、SubscriptionForm、AddSubscription 和 create/update/archive/remove/undo/reorder。卡片层级、字号密度、额度条、多账号展开/分组、信息顺序及当前色彩均保持；不要重写成原型大金额/厚底卡片。Button/Card/Table/Tabs/Sheet/Dialog/Field/Select/Progress/Collapsible 继续现有 base-mira 订阅展示 variant；原排序用 dnd-kit，展开用 Motion。

统一 selector/ViewModel 保留原 Field/Subscription，处理产品名、分类、价格、真实 lifecycle、autoRenew unknown、来源与观察时间；搜索和排序不在各组件重复写金额/日期规则。分类和最近付款从 SC-005 合同读取。

详情沿现有 Sheet 尺寸/信息分区/排版，保持所有额度窗口、余额与 Key 预算、会员/续费/试用日期、多账号和付款/额度共享关系；最近付款在后方渐进补充或链接消费页，不挤占原权益主区。自动来源未知显示未提供；编辑保留自动字段保护，不把原型布尔状态和单一 resetDate 覆盖生产对象。手动表单保留既有周期；季度入口在 SC-007 贯通后加入。

新增入口先发现/登录/Key，再可选手动记录；不得用原型手动表单代替账号流程。已删除/归档订阅的付款依 SC-005 保留；失败保持草稿，冲突显示重新读取/继续编辑入口，不静默覆盖。

## 可观察验收

先用相同订阅内容对照当前旧版基线，确认卡片/列表/详情的字号、密度、颜色、额度条、账号分组及信息层级保留，新外壳只改变可用列宽。新建手动记录、编辑、归档/恢复、删除/撤销，返回列表定位仍合理，重启后保存。旧 revision 保存冲突时草稿还在。自动记录可改本地金额/分类/备注但不能改供应商日期/额度；unknown、明确零、过时、多账号、多窗口和长中文均可读。最近付款与消费页一致，删订阅不删付款。

复用 renderer-entitlements/backend 的相关测试和实际 Electron 双主题表单/详情操作；不以 Mock client 测试替代真实 IPC。

## 依赖与进展

完整验收前置 SC-002、SC-005。SC-005 未完成时可先迁现有 CRUD，不能将最近付款分区标完成。账号入口行为与 SC-004 共同使用 AddSubscription，避免各造一套。状态 implemented：旧订阅表格/卡片/详情保持，分类、最近付款与记录付款入口已接入；桌面检查通过，用户验收 pending。
