# FE-004 在详情抽屉核对收费日期与额度来源

父任务：[FE-000](FE-000.md)。前置：[FE-003](FE-003.md)。依据：[前端规格第 3、4 节](../specs/frontend-first.md)、PRD 第 03、08、09 章。

## 目标与范围

点击卡片即可在右侧查看完整上下文，关闭后回到原位置。后续订阅表格与日历复用同一个抽屉，避免每个页面各造一套详情状态。

采用约 460 宽、独立滚动的详情抽屉，包含收费安排、全部额度窗口、来源和历史、日历与提醒四组。展示完整开始日、续费日、有效期及未知状态，并按字段展示更新时间。

支持手动锁定字段与探测值的对比，用户选择保留或采纳；探测值必须显示是模拟数据。历史展示模拟服务实际记录的观察或本地修改，不补造完整消费曲线。

提供编辑、暂停模拟连接和官方页面入口的回调。跳转官网只能用经过验证的 HTTPS 链接；不执行未知 URL 协议或本地命令。

## 验收

- 卡片打开详情，Esc、关闭按钮和遮罩按预期关闭；焦点回到触发卡片，原滚动位置不变。
- 手动锁定日与不同模拟探测日同时出现，未经选择不覆盖；选择后卡片同步更新。
- 同一详情可切换账号并正确展示对应的窗口、来源和付款关系。
- 窄窗口仍可读，长名称、较多窗口与较长历史不会遮住关闭或主要动作。
- 信息分组可展开，关键日期不必靠 hover 才能看到。
