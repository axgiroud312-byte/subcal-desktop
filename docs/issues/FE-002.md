# FE-002 切换十二种演示场景并保留演示编辑结果

父任务：[FE-000](FE-000.md)。前置：[FE-001](FE-001.md)。依据：[前端规格第 3 至 7 节](../specs/frontend-first.md)、PRD 第 03、09、15 章。

## 目标与范围

建立后续所有页面共同使用的数据合同、MockSubCalClient、演示存储和场景入口。用户不需要改代码就能进入空白、正常和异常状态；切换页面看到同一份数据。

定义订阅、账号、付款关系、额度池、单字段来源与时间、日程、连接、日历目标及模拟操作状态。服务接口异步返回，支持稳定 ID、revision、取消或忽略失效请求、结构化错误。

内置规格中的十二个场景，并提供可收起的预览工具。使用可注入演示时钟，当前演示日期可见。localStorage 由服务层单点访问，带 schemaVersion；加载失败提供恢复入口，不悄悄丢数据。

实现后续共同使用的金额/状态格式化、共享费用去重、周期日程投影等纯规则；不把完整后端调度器或 SQLite 塞进此任务。

## 必要边界

- billingGroupId 与 quotaPoolId 分离；同付费关系不自动合并额度。
- 日期未知不推算；零、未知、无限量、不适用、过时和部分成功是不同状态。
- 模拟成功保留 dataOrigin 或等价字段，不能被组件忽略。
- 重置演示空间要说明覆盖范围；切换场景不静默销毁未保存输入。
- 源码中的 fixture 是输入，由服务消费；页面不直接导入和修改 fixture。

## 验收

- UI 可选十二种场景；至少能在预览工具中看到场景名称、条目数和演示时间，页面随后逐步接入。
- 演示编辑经服务保存，刷新窗口与重开后不丢失；重置只影响本产品演示命名空间。
- 少量规则测试覆盖月末不漂移、闰年、日期型时区、币种分列、共享费用去重与空值不归零。
- 模拟刷新可以部分成功；陈旧或已取消的异步请求不能覆盖新场景。
- 不包含真实密码、Key、登录 Token 或供应商网络请求。

## 当前进展

实施：`src/shared/types.ts`、`rules.ts` 与 `src/renderer/service/MockSubCalClient.ts` 提供统一异步合同、revision、可注入演示时钟、单点存储、十二个独立场景、备份校验和模拟任务隔离。概览底部“展开预览工具”可切换、推进时钟和明确重置当前场景。

已验证：`npm run test:rules` 的 17 项高风险规则与服务检查通过，含月末/闰年、DST 日历日期、定点金额、多币种及共享费用、空值、保存/重启、并发、部分成功、归档与日历状态机。真实窗口逐一切换十二场景，重启保留场景与编辑。损坏存储保留原内容，需明确恢复。分支/PR：无。用户验收：未进行。
