# FE-013 让导航、页面空间和公共反馈保持克制一致

父任务：[FE-011](FE-011.md)。前置：[FE-012](FE-012.md)。依据：[视觉基础第 4.1 节](../design/visual-foundation.md)。

## 目标与范围

重整 `App.tsx` 的桌面壳、四项顶部导航、主操作、预览身份和通知区域。交付可承载后续页面的统一内容区、标题/工具栏约定，以及共享 Sheet/Dialog/Toast 的挂载方式。

## 实施要点

- 概览 / 订阅 / 日历 / 连接的选中态、hover、焦点统一；新增订阅为主操作，设置使用克制的图标入口。
- 预览身份用一处短标记表达，预览工具默认折叠；外部操作仍保留局部模拟说明。
- 页面使用统一边距和工具栏节奏，允许自然滚动；四导航在窄窗口仍能访问，不用任意压小字体解决溢出。
- 公共错误/通知分配合理位置，Toast 不遮住保存或冲突处理；重复事件不弹两套通知。
- 将旧全局布局样式逐步收敛，避免页面修改再次反向影响主导航。

## 验收方法

- 1280×820 与 960×640 实际窗口均能切换四页、打开新增与设置；有明确当前页面和键盘焦点。
- 深浅色切换无错误主题浮层；Windows 原生标题栏、托盘恢复窗口、页面滚动位置可用。
- 导航区、主要内容区和临时反馈层级清楚；没有一排场景调试按钮抢占首屏。
- 记录代表截图与尺寸；运行必要的类型检查和受影响导航操作。
