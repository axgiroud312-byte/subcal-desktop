# FE-007 查看连接能力并演示刷新与异常恢复

父任务：[FE-000](FE-000.md)。前置：[FE-004](FE-004.md)。依据：[前端规格第 4、6、7 节](../specs/frontend-first.md)、PRD 第 05、06、09、10 章。

## 目标与范围

完成连接管理页及卡片/详情的联动，用户能看懂哪些字段计划支持自动读取、为何某次模拟查询失败，以及下一步怎么处理。

展示五个正式适配器目标的能力边界以及实验和手动目录。连接流程选择示例账号 → 模拟探测 → 字段预览 → 确认绑定，不提供真实凭据输入。

所有刷新入口调用同一模拟任务服务；连续点击合并，限流期间显示下一允许时间。支持暂停单项、暂停全部、重新连接、断开绑定；断开不删除订阅资料。

覆盖认证失效、权限不足、限流、离线、缺运行时、结构变化和部分成功。模拟恢复不能更新不属于本次成功结果的字段时间。

## 验收

- 从卡片或详情进入对应连接能定位正确账号，恢复后原卡片状态更新。
- 连续点击刷新只产生一个在途模拟任务；限流时没有无限重试。
- 旧余额保留并带旧时间；认证失败不将订阅变成已到期。
- 切换场景或断开连接后，迟到结果不能覆盖新状态。
- 错误文案带具体动作，首页不显示堆栈；诊断可预览并导出实际生成的脱敏示例 JSON。
- 所有成功处明确标记模拟；没有实际查询、安装 CLI、登录或读取系统凭据。
