# FE-017 让连接恢复、设置和预览工具使用统一交互

父任务：[FE-011](FE-011.md)。前置：[FE-012](FE-012.md)。依据：[视觉基础第 4 节](../design/visual-foundation.md)。

## 目标与范围

改造 `ConnectionsPage.tsx`、`Settings.tsx`、`settings.css` 以及预览工具内容。让状态、恢复动作、偏好和导入反馈易于定位，长诊断与低频工具按需展开。

## 实施要点

- 连接项按身份、状态、更新时间、主要恢复动作排列；详细能力和诊断放折叠区，当前可执行动作直接可见。
- 设置使用一致的 Field、Switch、Select、Separator 和分组；每项偏好有明确当前值与生效结果。
- 备份、导入预览、确认恢复使用统一 Dialog / AlertDialog，显示原有差异与作用范围。
- 场景与时钟工具默认折叠，统一基础控件；不要将所有异常场景按钮作为首屏导航。
- 保留主题、密度、减少动效、托盘等现有偏好与持久化；主题状态只由现有偏好入口驱动。
- 预览工具的 App 挂载位置与 FE-013 共用已有入口约定，避免两项任务分别创建面板。

## 实际改动与组件使用点

1. **连接与异常恢复（`src/renderer/pages/ConnectionsPage.tsx`、`src/renderer/pages/connections.css`）**：
   - 将样式引用从旧共享 `calendar-connections.css` 切换为独占 `connections.css`（置于 `@layer components`，全部颜色、字号、字重 400/500/600、间距与圆角均引用 `src/renderer/styles/tokens.css`）。
   - **卡片信息层级**：按「品牌与身份（`BrandIcon` + 供应商 + 演示账号 + 区域 + `模拟来源`）→ 模拟状态（`StatusBadge`，`ready` 使用中性 `neutral` 样式，不将模拟就绪涂成真实连接成功绿色）→ 更新时间与字段时间保留说明（最后成功时间、最后尝试时间、`nextAllowed` 重试时间、`partial` 字段级旧时间保留）→ 关联订阅与锁定冲突入口 → 直接可见的结构化错误与可执行恢复动作」排列。
   - **直接可执行恢复动作与三步向导**：`模拟刷新`、`模拟重新连接 / 探测恢复`（或 `切换示例身份 / 重新探测`）、`恢复采集 / 暂停采集`、`脱敏诊断`、`断开绑定` 直接可见；限流状态（`rate_limited`）直接在错误区提供 `推进演示时钟 +5 分钟（预览工具操作）` 按钮；离线状态提供 `模拟恢复联网并补查一次`。三步恢复向导使用 `Field` + `FormSelect`（`1. 选择预置示例身份`）、`Button`（`2. 开始模拟探测`、`3. 确认绑定「…」并恢复采集（模拟）`），保留连接代次校验与迟到响应丢弃语义。
   - **默认折叠长能力与脱敏原文**：每张连接卡的「支持字段、未提供字段、采集路线、适配器版本与代次运行次数」使用 `@/components/ui/collapsible` 默认收起；页面底部「订阅接入目录与支持等级边界（PRD 第 05 章对照）」使用 `Collapsible` 默认收起；脱敏诊断弹窗（`Modal`）内直接展示诊断范围与导出按钮，长 JSON 原文通过 `Collapsible`（`展开脱敏诊断 JSON 原文`）默认收起。
   - 操作图标统一使用 `lucide-react`（取代 `⚠` 等操作区文本符号），品牌标识使用本地 SVG `BrandIcon`。

2. **设置、备份恢复与隐私许可（`src/renderer/components/Settings.tsx`、`src/renderer/components/settings.css`）**：
   - 使用 `@/components/ui/tabs`（`Tabs`、`TabsList`、`TabsTrigger`、`TabsContent`）组织「显示与提醒」「备份与恢复」「隐私与许可」三组标签页（角色为 `tab` / `tabpanel`）。
   - **显示与提醒**：使用 `FieldGroup`、`Field`、`FieldLabel`、`FieldDescription`、`FormSelect`（主题、阅读密度、额度显示、显示时区、新增记录的提醒方式）、`Switch`（减少动态效果、关闭窗口后保留在系统托盘）、`Input`（CNY / USD 钱包低余额阈值）及 `Separator` 紧凑分组。所有即时偏好直接调用 `client.setPreferences` 持久化，不另建第二套主题或动效 state；钱包低余额阈值草稿未保存时显示 `待保存草稿` 状态与 `还原已保存值` 按钮，关闭设置弹窗时由受控 `AlertDialog`（`有未保存的钱包阈值修改`）拦截保护（支持 `继续编辑`、`放弃未保存修改`、`保存阈值并关闭`）。
   - **备份与恢复**：保留 `导出演示备份 JSON` 与 `选择备份并预览`；预览卡片展示当前空间与备份空间条数、新增/覆盖/移除差异及恢复后全部模拟连接与 3 个日历目标自动暂停说明；点击 `恢复演示资料…`（`data-testid="open-restore-confirm-btn"`）打开受控 `AlertDialog`，由其中的 `确认恢复演示资料`（`data-testid="confirm-restore-btn"`）执行恢复，保留提交前 `readSelectedFile` 文件变更校验、损坏文件错误提示与取消不改数据语义。
   - **隐私与许可**：更新旧“仅使用文字后备”说明，准确记录本地单色品牌 SVG（`src/renderer/assets/brands/`，源自固定版本 Simple Icons CC0-1.0 与 `@lobehub/icons-static-svg` MIT）、未收录品牌文字后备、`lucide-react` 操作图标及 `base-mira` 组件基础，明确说明上游图标开源许可仅覆盖图形文件本身、**不包括任何品牌商标许可**，并指向 `docs/assets.md` 与 `docs/design/component-adoption.md`。

3. **预览工具说明（主代理已实现并挂载）**：
   - 主代理已将预览工具抽出为 `src/renderer/components/PreviewTools.tsx` 并在 `App.tsx` 统一挂载，采用 `Collapsible` 默认收起、`FormSelect` 十二场景切换、演示时钟推进按钮、受控 `AlertDialog` 重置当前场景，并内嵌 `ComponentPreview`（含标记为“组件示例 · 非实际消费”的 Recharts 3 示例与空状态切换）。本任务遵循约定不改挂载、不重复创建面板。
