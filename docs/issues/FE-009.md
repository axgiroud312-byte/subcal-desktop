# FE-009 保存偏好并通过托盘与备份继续使用前端

父任务：[FE-000](FE-000.md)。前置：[FE-005](FE-005.md)、[FE-007](FE-007.md)。依据：[前端规格第 1、2、6 节](../specs/frontend-first.md)、PRD 第 08、12、14 章。

## 目标与范围

完成主题、密度、剩余/已用、时区和提醒偏好的保存；提供真实最薄托盘入口，以及演示元数据备份、导入预览和恢复。

托盘能打开窗口、显示置顶摘要、暂停/恢复模拟刷新并完全退出。第一次关闭到托盘时说明“预览仍在运行”，不能写“真实心跳持续采集”。系统开机启动、系统定时通知和真实云备份不在本阶段；相应控件禁用或注明后续实现。

备份必须实际生成可打开的 JSON；只包含演示记录、偏好和模拟日程。导入先校验版本、结构和大小，再预览新增或覆盖范围；确认提交之后更新全部页面。文件改变后原预览失效。

## 验收

- 关闭窗口到托盘后能重新打开，完全退出确实结束本次预览进程。
- 修改显示偏好后各页一致，重启恢复；减少动态效果设置受到尊重。
- 导出演示资料、修改一条记录，再导入旧备份，预览差异和最终恢复一致。
- 无效 JSON、错误版本、超限文件不会破坏当前数据；提示可理解。
- 导入后模拟日历目标暂停待核对；备份不包含任何真实凭据。
- 没有真实开机启动或系统通知能力时不提示“已开启”，仅允许页面内样式预览。

## 当前进展

实施：原生托盘与独立开发资料目录、持久化主题/密度/额度方向/时区/提醒偏好、真实 JSON 保存/选择文件桥、导入预览和恢复均已实现。提交导入前重新读取已选择文件，发生内容变化则旧预览失效；恢复后全部模拟目标暂停。

已验证：设置中导出实际 JSON→选择并预览→预览后外部改文件被拒绝→重新选择恢复成功；模拟连接与日历目标全部暂停。主题与顺序重启保留。真实窗口关闭后保留进程、Windows 原生托盘图标打开窗口、退出菜单回调完全退出。文件路径由测试替代系统选择器返回，文件读写真实执行；首次关闭说明由自动化确认，菜单退出调用实际回调，测试边界详见 FE-010。备份版本/结构/大小/损坏恢复通过规则检查。系统开机启动/定时通知明确为后续能力。分支/PR：无。用户验收：未进行。
