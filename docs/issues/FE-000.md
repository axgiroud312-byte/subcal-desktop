# FE-000 完成可试用的 SubCal 桌面前端预览

## 目标

让用户在真实桌面窗口内看见并操作主要界面，验证 Magpie 风格的信息组织、订阅编辑与日历表达，然后再进入真实服务集成。

## 范围与依据

以 [前端执行规格](../specs/frontend-first.md) 和 [PRD](../../SubCal-Desktop-V1-PRD.md) 为准。子任务为 [FE-001](FE-001.md)、[FE-002](FE-002.md)、[FE-003](FE-003.md)、[FE-004](FE-004.md)、[FE-005](FE-005.md)、[FE-006](FE-006.md)、[FE-007](FE-007.md)、[FE-008](FE-008.md)、[FE-009](FE-009.md)、[FE-010](FE-010.md)。

交付概览、订阅、日历、连接四页与抽屉、编辑、设置、托盘、十二种演示场景。所有数据与同步行为保持明确的预览边界。真实 OAuth、供应商调用、SQLite、日历系统写入及生产安装包另行实施。

## 总体验收

- 在 Windows 开发模式启动真实 Electron 窗口，可以完成四页导航；浏览器网页不能作为唯一交付。
- 首屏能看懂近期行动、三类卡片、不同的续费与重置日期，未知值不变成零。
- 新增一项手动记录，改期后概览、详情、日历一致；重启能恢复。
- 能演示认证失效、限流、部分成功、过时、日历冲突及其恢复，并始终有模拟标识。
- 本地备份可预览恢复；没有真实秘密或外部写入。
- 完成必要检查并说明实际平台范围；没有 Mac 时写未实测，不伪称跨平台已验收。
- 提供精确启动入口、已实现/已验证/待用户验收清单。用户尚未试用时本任务保持待验收。
