# FE-005 从品牌目录完成订阅的新增编辑与删除恢复

父任务：[FE-000](FE-000.md)。前置：[FE-004](FE-004.md)。依据：[前端规格第 1、3、4、6 节](../specs/frontend-first.md)、PRD 第 07、08 章。

## 目标与范围

完成订阅管理的端到端流程：列表搜索 → 选择品牌或自定义 → 新增 → 查看详情 → 编辑收费安排 → 归档或删除 → 必要时撤销。

“订阅”页采用紧凑管理表格，与概览的卡片分工清晰；品牌目录放在新增流程内。显示正式自动目标、实验、手动的规划等级，同时明确本阶段所有外部服务均未连接。

表单分基础与收费、可选额度记录、提醒。名称必填，其余未知允许留空；校验价格、周期和日期关系，但不得用价格校验规则阻止合法的负现金余额示例。

修改调用统一服务，更新卡片、详情和日程投影。关闭未保存表单提供保存或放弃；保存失败保留输入。无实际后端时不能出现可输入真实 Key 的连接步骤。

“已在官网取消自动续费”需要用户确认已知有效期，更新的是演示记录。归档与删除分开；未来模拟日程处理范围明确，删除操作可在 8 秒内撤销演示事务。

## 验收

- 从空场景添加只有名称的自定义订阅，能保存、查看、再补齐金额及日期。
- 编辑日期与金额后卡片、详情和服务内日程投影一致，重启仍保留。
- 未保存关闭及保存失败不丢输入；重复提交不产生重复记录。
- 取消自动续费不被描述成已替用户执行退订，不从扣费日推断已付有效期。
- 归档可以恢复；删除范围确认明确；撤销恢复原记录和对应模拟日程。
- 搜索、排序、归档筛选及无匹配结果可用，不能只有演示静态表格。

## 当前进展

实施：可搜索/排序/归档筛选的管理表格、品牌规划目录、名称必填其余可空的新增编辑弹窗、独立字段来源、日期和金额校验、revision 冲突保留输入、明确有效期的本地取消续费、归档恢复、删除范围与 8 秒撤销。

已验证：从空场景用键盘新增仅名称记录→补金额与日期→改期→详情/月历联动→删除→撤销→重启仍保留。连续 Escape 不会绕过未保存选择；编辑未变字段保留观察时间。幂等创建、版本冲突、负钱包余额合法、归档生命周期恢复及受管事件抑制通过服务检查。负责人：Gemini 4 Argon Contributor 实现，主 Agent 整合。分支/PR：无。用户验收：未进行。
